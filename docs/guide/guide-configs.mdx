Recyclarr can create ready-made configuration files, called templates, that deploy a TRaSH Guides
quality profile exactly as the guide describes it. Recyclarr generates one template for each guide
quality profile, so new guide profiles become available as the guide updates.

Templates use [guide-backed quality profiles][qp] and [custom format groups][cfg] to synchronize all
mandatory elements of the guide profile. A single `trash_id` reference per quality profile replaces
what previously required multiple include templates.

## Choose a Profile {/*#choose-profile*/}

Read the TRaSH Guides quality profile descriptions to decide which profile fits your setup:

- Radarr: [Quality Profiles][radarr-profiles-trash], plus [Anime][radarr-anime-profiles-trash],
  [French][radarr-french-profiles-trash], and [German][radarr-german-profiles-trash] profiles
- Sonarr: [Quality Profiles][sonarr-profiles-trash], plus [Anime][sonarr-anime-profiles-trash],
  [French][sonarr-french-profiles-trash], and [German][sonarr-german-profiles-trash] profiles

## Find the Template ID {/*#template-id*/}

List the available templates:

```bash
recyclarr config list templates
```

The list shows each template's ID next to the name of its guide profile, so you can match the
profile you chose to its ID. See [`recyclarr config list templates`][cli-list] for the options.

## Preview a Template {/*#preview*/}

To see what a template contains before you use it, write it to a file outside your configuration
directory with `--path`:

```bash
recyclarr config create -t hd-bluray-web -p ./hd-bluray-web.yml
```

In Docker, write the file inside the container and print it:

```bash
docker exec recyclarr recyclarr config create -t hd-bluray-web -p /tmp/hd-bluray-web.yml
docker exec recyclarr cat /tmp/hd-bluray-web.yml
```

The file has one instance with placeholders for `base_url` and `api_key`, a quality definition, the
guide-backed quality profile, and the profile's custom format groups. Optional groups are commented
out so you can enable the ones you want. See [Templates][templates] for details.
